# Componentes externos

LooperMaster utiliza Windows Forms y .NET Framework de Microsoft.

El ZIP de LooperMaster contiene la aplicación y su documentación. FFmpeg y FFprobe se detectan o descargan durante el uso. La descarga selecciona una compilación GPL de FFmpeg-Builds e incluye su archivo de licencia en la instalación local de las herramientas.

- Proyecto FFmpeg y código fuente — https://ffmpeg.org/
- Descargas del proyecto — https://ffmpeg.org/download.html
- Compilaciones utilizadas y enlaces a sus fuentes — https://github.com/FFmpeg-Builds/FFmpeg-Builds

La caché de herramientas contiene `LICENSE.txt` y `ORIGEN.txt`, con el enlace y el SHA-256 correspondientes a la descarga.
